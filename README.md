# Sales Agents Department

One Director runs your sales process through sub-agents and asks you only for the key approvals. Nothing is ever sent from the app: sending stays with you.

## Install (Windows)
1. Open the latest release: https://github.com/engahmedmamdouh93-bit/Sales-Department/releases/latest
2. Download Sales-Department-Setup-<version>.exe and double-click it. It installs in one click and opens the app.
3. If Windows shows "Windows protected your PC": More info, then Run anyway (the installer is not code-signed).

## Connect Claude
- Claude Code login: install Claude Code, run `claude` once in a terminal and sign in. In the app: menu, Settings, Connections, Reconnect, then Test.
- Or paste an API key in Settings, Connections.

## Update
Create a new release with a higher tag (for example v0.7.1). In the app: Settings, Updates, Check for updates, Update now.

## Data
Your businesses and settings stay on your computer. Use Settings, Data and backup to copy a backup.
